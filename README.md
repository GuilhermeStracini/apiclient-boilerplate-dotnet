# .NET API Client Boilerplate

Template reutilizável para criar clientes e SDKs de APIs em C#/.NET.

O projeto fornece uma estrutura organizada para implementação, testes, empacotamento e distribuição de bibliotecas NuGet, permitindo que você concentre esforços na integração com sua API.

## ✨ Funcionalidades

- Estrutura organizada para bibliotecas .NET
- Testes unitários e de integração
- Scripts de configuração automática
- Exemplo de pipeline CI/CD
- Empacotamento NuGet
- Configuração para documentação
- Fácil personalização de nomes e namespaces

## 📋 Pré-requisitos

- .NET SDK
- Git
- Visual Studio, Visual Studio Code ou JetBrains Rider
- Conta no GitHub
